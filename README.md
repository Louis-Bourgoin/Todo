# Todo App - Web Version

Cette version est une version web simple de mon application de gestion de tâches.

## Utilisation

1. Dézipper le dossier si besoin
2. Ouvrir `index.html` dans un navigateur
3. Utiliser l'application normalement

## Fonctionnalités

- Ajouter des tâches
- Modifier des tâches
- Définir des deadlines
- Marquer comme importantes
- Archiver des tâches
- Rechercher et filtrer

## Sauvegarde

Les données sont sauvegardées localement dans le navigateur (`localStorage`).

⚠️ Important :
- Les tâches restent sur le même navigateur / appareil
- Si les données du navigateur sont supprimées, les tâches seront perdues

## But du projet

À la base, cette application a été pensée pour répondre à un besoin réel de gestion simple mais pratique au quotidien.
